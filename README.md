## Open data platform for Indonesia

I build and maintain [api-datasets-indonesia](https://github.com/prodhokter/api-datasets-indonesia): a public, read-only REST API (Go and PostgreSQL) and CSV collections compiled from official government sources. It runs at [api.ibnuhabib.web.id](https://api.ibnuhabib.web.id), no API key required.

| Dataset | Records | Source |
| --- | --- | --- |
| [dataset-sekolah-indonesia](https://github.com/prodhokter/dataset-sekolah-indonesia) | 547,019 schools, Top 1000 LTMPT ranking | Dapodik, Kemendikbud |
| [dataset-kbbi-indonesia](https://github.com/prodhokter/dataset-kbbi-indonesia) | 209,868 dictionary entries, 1,453 word pairs | KBBI |
| [dataset-wilayah-indonesia](https://github.com/prodhokter/dataset-wilayah-indonesia) | 38 provinces, 514 regencies/cities, 7,285 districts, 83,762 villages | Kepmendagri 2025 |
| [dataset-program-studi-indonesia](https://github.com/prodhokter/dataset-program-studi-indonesia) | 4,971 study programs with quotas, demand, and passing grades | SNPMB 2024 |
| [dataset-perguruan-tinggi-indonesia](https://github.com/prodhokter/dataset-perguruan-tinggi-indonesia) | 143 universities with capacity and applicant statistics | SNPMB 2024 |

## Projects

- **[Segmenta](https://github.com/prodhokter/segmenta)**: open-source download manager and media grabber. Rust core with Tauri v2 and Svelte 5, multi-connection download slicing, HLS media extraction, and a Manifest V3 browser extension.
- **[AntiDistract](https://github.com/prodhokter/anti-distract)**: local-first productivity app with a Pomodoro timer, OpenCV face detection, website blocking, and a virtual garden. Python and PyQt6, runs on Windows, macOS, and Linux.
- **[pens-kp-bot](https://github.com/prodhokter/pens-kp-bot)**: automation bot that fills internship logbooks for PENS students through Online MIS CAS.
